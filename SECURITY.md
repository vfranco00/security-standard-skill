# Política de segurança

Reporte vulnerabilidades pela aba **Security** deste repositório no GitHub, em **Report a vulnerability**. O reporte fica privado, visível só para você e para quem mantém o repositório.

Descreva o problema e como reproduzi-lo, sem segredo, credencial ou dado pessoal. Não abra issue pública para falha de segurança.
